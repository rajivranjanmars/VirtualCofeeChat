# Virtual Coffee Chat

Static frontend prototype from the Citrix Challenge at R.U.Hacking 2021. It presents upcoming virtual coffee events, a profile page, public events, and a custom-event form.

## Getting started

Run `python -m http.server 8000` here and open `http://localhost:8000/`. The pages contain sample data; event persistence and authentication are not implemented.
